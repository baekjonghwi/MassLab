# 인스타 광고물

**갈래는 둘이고, 스킬은 하나다.**

| 사용자가 하는 말 | 내놓는 것 |
|---|---|
| "스토리 올릴게" · "게시물 올릴게" · "카드 만들어줘" | 카드 PNG + 캡션 + 해시태그 |
| "영상 올릴게" · "릴스 찍었어" | 영상 소개글 + 해시태그 (**그림 없음**) |

⛔영상 쪽에서 카드를 만들지 말 것. 영상은 영상이 그림이다 — 카드를 얹으면
사용자가 안 쓸 파일만 늘어난다.

## 🔴어느 말로 쓰는지부터 (2026-09-05 사용자 결정)

- **카드 그림 안의 글은 무조건 영어.** 그림에는 번역이 안 붙는다.
- **글귀(캡션·영상 소개글)는 영어 먼저, 한국어 그 다음.** 두 벌을 한 글에 담는다.
- ⛔번역하지 않는다 — 각각 그 말로 처음부터 짓는다.

자세한 것과 글자 수 상한은 [`reference/copy.md`](reference/copy.md).

## 1. 무엇을 알렸는지부터 정한다

🔴**지어내지 않는다.** 사용자가 바꾼 것을 사용자보다 잘 알 수 없다.

- 사용자가 무엇을 했는지 이미 말했으면 → 그걸 쓴다.
- 흐릿하면(“오늘 업데이트한 거 올려줘”) → 해당 제품 저장소의 최근 커밋을 읽는다.
  제품 폴더는 `D:\CODE` 아래 형제다(CLAUDE.md 표). 커밋 글이 한국어 서술문이라
  그대로 재료가 된다.
- 그래도 모르겠으면 **한 번만 묻는다.** 두 번 묻지 말 것.

그리고 **누구에게 무엇이 좋아졌는지** 한 문장으로 정리한 뒤에 글을 짓는다.
기능 이름이 아니라 **없어진 수고**가 광고의 내용이다.
"주소 검색 추가" 가 아니라 "대지 찾느라 지도 끌던 시간이 없어졌다".

## 2. 어느 판인지 정한다

| 판 | 크기 | 몇 장 | 언제 |
|---|---|---|---|
| `story` | 1080×1920 | **1~3장** | 가볍게 알릴 때. 24시간이면 사라진다 |
| `post` | 1080×1350 | **3~6장** | 남길 것. 캐러셀로 넘겨 본다 |
| `square` | 1080×1080 | 1~2장 | 잘 안 쓴다. 사용자가 콕 집을 때만 |

⚠️스토리는 인스타 UI 가 위아래 약 250px 씩 가린다 — CSS 가 이미 그만큼 비워 두었으니
**판을 꽉 채우려 들지 말 것.**

## 3. spec 을 쓴다

`D:\CODE\_social\<YYYYMMDD>-<슬러그>\spec.json` 에 쓴다.
🔴저장소 안에 쓰지 말 것 — MassLabs 는 배포되는 프로젝트라 빌드 컨텍스트가 딸려 올라간다
(CLAUDE.md 의 폴더 규칙과 같은 이유다).

카드 종류와 칸 이름은 [`reference/spec.md`](reference/spec.md) 에 전부 있다.
본보기는 [`example.json`](example.json).

**한 장에 한 가지만 담는다.** 두 가지가 들어가는 순간 둘 다 안 읽힌다.
글자 수 상한은 [`reference/copy.md`](reference/copy.md) — 넘기면 판 밖으로 조용히 새어 나간다.

## 4. 그린다

```bash
node .claude/skills/insta-card/render.mjs "D:/CODE/_social/<폴더>/spec.json"
```

`spec.json` 옆에 `slug` 이름의 폴더가 생기고 `01-cover.png` … 그리고 `caption.txt` 가 놓인다.

- `--out DIR` 다른 데로 보낸다 · `--only 2,3` 몇 장만 다시 그린다 · `--keep` 그린 HTML 을 남긴다
- 처음 한 번은 글꼴을 받아 `.fonts/` 에 넣는다(약 1.4MB, git 에 안 올라간다). 그 다음부터는 인터넷이 없어도 된다.

## 5. 🔴그린 그림을 **반드시 눈으로 본다**

Read 로 PNG 를 열어 확인한다. 최소한 첫 장과 글이 가장 긴 장.

글이 길면 **오류 없이 조용히** 판 밖으로 나간다 — 아무도 안 알려 준다.
넘쳤으면 CSS 를 건드리지 말고 **글을 줄인다.** 판이 아니라 글이 길었던 것이다.

확인할 것:
1. 글이 아래·오른쪽으로 안 새는지
2. 스토리라면 위아래 250px 안에 중요한 게 안 들어갔는지
3. 다크로 뽑았으면 스크린샷·로고가 어두운 바닥에서 떠 보이는지
4. `**굵게**` 가 실제로 굵게 나왔는지

## 6. 사용자에게 건넬 때

만든 폴더 경로, 몇 장인지, 캡션·해시태그를 그대로 보여 준다.
파일을 다른 기기에서 볼 사람이면 SendUserFile 로 첫 장을 같이 보낸다.

## 영상 갈래

그림을 만들지 않는다. 글만 낸다 — 형식은 [`reference/copy.md`](reference/copy.md) 의 "영상 소개글".
사용자가 영상 내용을 말해 주지 않았으면 **무엇을 찍었는지 한 번 묻는다.**
영상은 커밋 로그로 유추할 수 없다.

## 지키는 것

- **디자인 규칙의 원본은 `masslabs-ui` 스킬이다.** 색·모서리·그림자·글자체를 손대야 하면
  거기부터 읽는다. `card.css` 는 그 토큰을 베껴 온 것이지 원본이 아니다.
- **UI 는 흑백이다. 색은 사용자 데이터의 몫이다.** 카드에 색을 얹지 말 것 —
  예외는 브랜드 마크와, 그림 안에 든 제품 화면(지도 색·팔레트)뿐이다.
- **주소를 화면 파일에 적지 않는다.** 제품 주소는 `render.mjs` 의 `SITE` 표가 갖고 있다
  (저장소의 `lib/products.ts` 와 같은 뜻이다).
- 🔴**지금 팔지 않는 것을 팔지 말 것.** 구독은 2026-08-21부터 안 판다
  (`lib/interim.ts` 의 `SUBSCRIPTION_LIVE`). archiMap 은 "로그인하면 PLUS 무료",
  LaserFish 는 "건당결제" 다. ⛔"월 $4.99" 같은 문구를 카드에 쓰지 말 것.
  값 이야기가 필요하면 홈의 가격 구역(`/#pricing`)으로 보낸다.
- 🔴**`/price` 를 주소로 적지 않는다** — 지금 홈으로 넘어간다(307). 프로필 링크로 보낸다.
