# MassLabs UI

**원본은 archiMap이다** (`D:\CODE\archiMap\public\styles.css`). 나머지 사이트가 그쪽을 따라간다.
값은 산문으로 옮기지 않는다 — 같은 폴더의 [`tokens.css`](tokens.css)가 값의 전부다.
새 화면을 만들 땐 그 파일의 블록을 프로젝트 `globals.css`에 **복사**해 넣고 시작한다.

## 값을 두 번 적지 않는다

이 문서에는 색 코드가 하나도 없다. 있으면 안 된다.
`tokens.css`와 여기 둘 다 값을 들고 있으면 언젠가 한쪽만 고쳐져 갈라진다.
색을 바꿔야 하면 archiMap → `tokens.css` → 각 프로젝트 `globals.css` 순서로 내려온다.

## 규칙

### 흑백
UI는 흑백이다. 색은 **사용자 데이터**의 몫이다 — 지도 레이어 색, 팔레트 스와치,
렌더 결과물. 버튼·테두리·배지에 색을 쓰기 시작하면 사용자 색이 안 읽힌다.
예외는 **브랜드 마크 하나** — 로고의 파스텔 배색은 그대로 둔다.

순수 검정(`#000`)과 순수 흰 바닥은 안 쓴다. 바닥은 회색(`--pan`), 그 위의 칸이
흰색(`--card`)이다. 다크에서는 짙은 회색 바닥에 그보다 밝은 회색 칸으로 같은 관계가 유지된다.

### 칸을 가르는 법
둥근 모서리가 아니라 **그림자**(`--cardsh`)가 가른다. 모서리는 얕게 —
칸 `--r`(8px), 버튼·입력칸 `--r2`(6px). 알약(999px)은 아주 드물게, 16px 이상은 안 쓴다.

### 다크
`color-scheme: light dark` 선언이 **먼저** 있어야 한다. 없으면 크롬 Auto Dark Mode가
밝은 페이지를 강제 반전시켜 흰 카드가 새까매지고, 사용자 색까지 뒤집힌다.
선언한 대가로 어두운 팔레트는 우리가 전부 준다.

- 다크 블록에서 **새 이름을 만들지 않는다.** 같은 이름의 값만 갈아 끼운다.
  한쪽에만 있는 이름이 생기는 순간 그 자리가 다크에서 조용히 깨진다.
- `--ac`/`--acx`는 다크에서 **뒤집힌다**(어두운 바닥 → 밝은 바닥). 강조 버튼에
  `bg-ac text-acx`를 쓰면 자동으로 맞고, `bg-black text-white`를 쓰면 다크에서 사라진다.
- ⛔`bg-white` · `text-white` · `#fff` 리터럴 금지. 전부 토큰으로.
  예외 = **사용자 색 위에 얹는 것**. 임의의 색 위의 반투명 오버레이(`bg-black/10`)나
  대비 계산으로 뽑은 글자색은 테마와 무관하므로 그대로 둔다.
- 🔴🔴사용자 색을 보여주는 자리(스와치·미리보기·지도 바닥)는 다크에서도 **흰 종이 위**에 둔다.
  같은 색이라도 검은 바탕에 놓이면 더 탁하고 어둡게 읽힌다 — 그 상태로 고른 색은 흰 배경에
  쓰는 순간 딴 색이 된다. 색을 다루는 도구에서 이건 화면이 거짓말을 하는 것과 같다.

### 흰 종이를 만드는 법 — `.paper`

값을 두 벌 적지 않고 예외를 만든다. 라이트 값을 `:root` 와 `.paper` **둘 다에** 걸고,
다크 블록은 `:root` 만 덮는다. `.paper` 요소는 루트가 아니라서 다크 규칙에 아예 안 걸린다:

```css
:root, .paper { --pan: …; --card: …; --tx: …; }        /* 라이트, 한 번만 */
@media (prefers-color-scheme: dark) { :root { … } }     /* 다크는 :root 만 */
.paper { color-scheme: only light; background: var(--pan); color: var(--tx); }
```

그리고 색이 놓이는 영역을 `.paper` 로 감싼다. 상단바·바닥글은 그 밖에 두어 어두워지게 한다.
Colorgram 은 `<main class="paper">` 한 겹이다.

🔴🔴**`light` 가 아니라 `only light`.** 둘은 뜻이 다르다 —
`light` 는 "라이트를 지원한다"는 **선언**이고, `only light` 는 "라이트만 쓴다,
브라우저는 건드리지 마라"는 **거부**다. 크롬 강제 다크(Auto Dark Theme)는 앞엣것으론
안 멈춘다: 배경은 물론 **인라인 `background-color` 까지** 알고리즘으로 어둡게 칠해,
팔레트 스와치가 통째로 탁해진다(2026-08-23 Colorgram 실측).
`color-scheme` 은 그 안의 네이티브 위젯(색 선택기·숫자 스피너·스크롤바)도 같이 밝게 남긴다.

⚠️**archiMap 이 멀쩡하다는 걸 근거로 삼지 말 것.** 저쪽 지도는 WebGL 캔버스라
크롬이 픽셀을 못 건드리는 것뿐이지, 방어가 돼 있어서가 아니다. DOM 으로 색을 그리는
화면은 전부 이 선언이 필요하다.

### 글자
영문 **Geist**, 한글 **에스코어드림**. 한 사이트 안에서 글꼴이 갈리지 않게 한다 —
서드파티 CSS(지도 컨트롤, 날짜 선택기)가 제 글꼴을 거는 자리는 `font-family: inherit`으로 되돌린다.

자간은 한 부호로 통일한다(−0.01em). 자간 부호가 갈리면 같은 글꼴도 다른 글꼴처럼 읽힌다.
**위계는 자간이 아니라 크기로 준다** — 주 메뉴 14px, 보조 동작 11.5px 식으로.

한글이 안 나오는 사이트에는 에스코어드림을 넣지 않는다(woff 세 벌은 순수한 로딩 손해다).

### 내보내기 파일
SVG 문자열을 만들어 내보내는 경로에는 **웹폰트를 넣지 않는다.** 외부 `@font-face` url을
참조하는 순간 캔버스가 오염돼 PNG·PDF 변환이 통째로 죽는다. 화면용 CSS와 내보내기용
문자열은 별개다.
